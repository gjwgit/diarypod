# Diary Pod Change Log

Noted here are the high level changes for the app.  Each update
includes a short user-oriented description.  The next release is 0.2
following incremental updates through the 0.1.n series.

You can run the app in your
[**browser**](https://diarypod.solidcommunity.au) or else download and
install locally the latest version from the [Solid Community
AU](https://solidcommunity.au) or directly: for **Android** as
[aab](https://solidcommunity.au/installers/diarypod.aab) or
[apk](https://solidcommunity.au/installers/diarypod.apk); for
**GNU/Linux** as
[deb](https://solidcommunity.au/installers/diarypod_amd64.deb) or
[snap](https://solidcommunity.au/installers/diarypod_amd64.snap) or
[zip](https://solidcommunity.au/installers/diarypod-linux.zip); for
**macOS** as
[dmg](https://solidcommunity.au/installers/diarypod-macos.dmg) or
[zip](https://solidcommunity.au/installers/diarypod-macos.zip); for
**Windows** as
[inno](https://solidcommunity.au/installers/diarypod-windows-inno.exe)
or [zip](https://solidcommunity.au/installers/diarypod-windows.zip).

Contributions are welcome. Visit
[github](https://github.com/gjwgit/diarypod) to submit an issue or, even
better, fork the repository yourself, update the code, and submit a
Pull Request. Coding documentation is
[available](https://solidcommunity.au/docs/diarypod/).

We make this project available for free so if you appreciate the app
then please show some ❤️ and tap on the star at
[GitHub](https://github.com/gjwgit/diarypod) to support our work.

This app has been pair programmed by [Graham
Williams](https://togaware.com/Graham.Williams.html) and [Claude
Code](https://claude.com/product/claude-code).
